# APinfo 2.0 Fase 1 — MVP Anti-burocracia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar MVP "vagas primeiro" que elimina o Outlook: candidatura e contato em lote 1-clique (10/lote, 30/dia), lista limpa tabela/cards com modal preservando seleção, CV/vaga canônicos com IA + taxonomia 500 skills, higiene 180d/14d com nudges n8n idempotentes.

**Architecture:** Next.js 15 App Router (SSR+PWA leve) + Postgres+Prisma+pgvector (tsvector+vector) para busca semântica <800ms. IA via OmniRoute (embeddings multilingual-e5 + LLM extração/score). n8n queue mode orquestra ingestão→indexação→notificação→expiração→proxy SES/Resend+WhatsApp. Cold start zero, seeding vagas curadas primeiro, ICP PME sem ATS.

**Tech Stack:** Next.js 15, shadcn/ui, Tailwind, Prisma, Postgres 16+pgvector, next-intl (PT-BR/EN), OmniRoute, n8n, Resend/SES (proxy via.*), OTP 5min

**Spec:** `docs/superpowers/specs/2026-11-07-apinfo-2.0-design.md`

## Global Constraints

- C1. Simplicidade brutal: toda ação principal em 1 clique ou seleção em lote. Regra: "outlook nunca abre".
- C2. LGPD granular: 4 consentimentos versionados (tratamentoBuscaV, contatoProxyV, nudgesV, iaReescritaV) com texto logado; checkbox único não basta.
- C3. Celular obrigatório como ID mínimo; outros canais opt-in; OTP WhatsApp/SMS 5min, rate limit.
- C4. Responsivo desde dia 1: tabela desktop / cards mobile, mesmo dado; breakpoints 360/768/1024/1280.
- C5. Multilíngue por arquitetura: next-intl, fallback PT-BR, embeddings multilíngues já no MVP.
- C6. IA invisível + n8n visível; retry+log+idempotência.
- C7. Performance: busca p95 <800ms (Fase1) / <1s spec, paginação server-side.
- C8. Cold start do zero; sem migração legada; seeding vagas primeiro; brand novo.

## Review Focus

- **CV com PDF escaneado/imagem sem texto extraível** → deve cair para form em branco com aviso "não foi possível extrair, preencha manual", não quebrar ingestão.
- **Busca vazia ou com typo ("Analsita Cluod remota 12k")** → deve retornar sugestão IA "quer dizer Analista Cloud?" + lista vazia com CTA, não 500.
- **Candidatura duplicada na mesma vaga (mesmo lote ou dias depois)** → deve bloquear com mensagem "você já se candidatou em 07/11" e não criar Application duplicada.
- **OTP expirado/3 tentativas erradas/bloqueio** → deve mostrar "código expirado, reenviar" com cooldown 60s, não liberar JWT.
- **Lote parcial: 1 vaga expirou entre seleção e clique** → deve confirmar 2/3 com feedback por item "1 vaga expirada" sem rollback total.
